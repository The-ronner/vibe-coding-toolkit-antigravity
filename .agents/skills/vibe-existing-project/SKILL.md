# Vibe existing project

Read `docs/prompts/12-existing-project-setup.md` and the linked guides before changing an existing project. Inspect product, stack, instructions, package manager, dependencies, integrations, local changes, tests, and current Antigravity discovery files.

Brainstorm only within the user's authorization. Preserve the existing framework, database provider, commands, permissions, custom instructions, and working integrations. Reconcile rather than duplicate `AGENTS.md`, `GEMINI.md`, `.agents/rules`, `.agents/skills`, `.agents/mcp_config.json`, memory, and client-specific files.

Evaluate installed versus discovered versus configured versus authenticated versus successfully exercised. Use the manifest for canonical documents, add only relevant skills, and record decisions and evidence in `docs/setup.md`. Run focused checks and compare the diff before completion. Do not publish, send messages, install Git blockers, or invent successful external integrations.
